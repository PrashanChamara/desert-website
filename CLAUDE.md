Project-level guidance for all Claude sessions. These instructions OVERRIDE default behavior.

## 1. Project Summary

**Desert Cubs Cricket Academy** — SEO-first marketing website for a UAE cricket academy with 6 centres (Dubai + Sharjah). Built on Flask with AI-powered weekly content automation via n8n.

**Core purpose:** Drive parent/student leads through high local SEO ranking. Every code decision should be measured against: does this help SEO, UX, or lead conversion?

---

## 2. Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Flask (Python 3), single-file app (`app.py`) |
| Templating | Jinja2, template inheritance from `base.html` |
| Styling | Custom CSS (`static/css/style.css`) + Tailwind utility classes inline |
| JavaScript | Vanilla JS only (`static/js/main.js`) — no frameworks |
| Content automation | n8n workflow → Gemini 2.5 Flash + Pollinations.ai |
| Production server | Gunicorn (`gunicorn-desertcubs` systemd service) |
| Auto-deploy | Cron every 15 min → `scripts/server_auto_deploy.sh` |

**No Node.js, no React, no build step.** Do not suggest npm, webpack, or frontend frameworks — this is a Flask/Jinja stack intentionally.

## 4. app.py Architecture

`app.py` is a single-file Flask app. Do NOT split it into multiple files unless explicitly asked — the current structure is intentional for a simple VPS deployment.

### Key sections (in order):
1. **CONFIGURATION** — constants: `BLOG_DIR`, `POSTS_PER_PAGE`, `WEBHOOK_SECRET`
2. **DATA: BRANCHES** — `BRANCHES` list of dicts (6 centres, hardcoded)
3. **DATA: TOURS / TOURNAMENTS / MASTER_CLASSES / EVENTS / SPONSORS** — hardcoded Python dicts
4. **HELPERS** — `get_blog_posts()`, `extract_post_meta()`, `get_active_tournament()`, `verify_webhook()`, `seo()`
5. **ROUTES** — all Flask route handlers
6. **WEBHOOK ENDPOINTS** — `/webhook/create-blog`, `/webhook/update-seo`
7. **ERROR HANDLERS** — 404

### Data constants pattern:
```python
# SCREAMING_SNAKE_CASE for data constants
BRANCHES = [{"id": "...", "name": "...", ...}]
TOURS = [...]
```

### SEO helper pattern:
```python
# Every route calls seo() and passes meta to template
meta = seo(
    title="Page Title | Desert Cubs",
    description="...",
    keywords="...",
    url="/route"
)
return render_template('page.html', meta=meta, data=DATA)
```

### Webhook security:
```python
# Always verify HMAC before processing webhook payloads
if not verify_webhook(request):
    abort(403)
```

## 5. Naming Conventions

### Python (app.py)
- Functions: `snake_case` — `get_blog_posts()`, `extract_post_meta()`
- Data constants: `SCREAMING_SNAKE_CASE` — `BRANCHES`, `TOURS`
- Route handlers: plain page name — `def blog():`, `def tours():`

### Blog posts (content/posts/)
- Pattern: `YYYY-MM-DD_slug-title.html`
- Max slug length: 60 chars (truncated at word boundary)
- Example: `2026-02-10_nutrition-for-juniors.html`

### Blog images (static/img/blog/)
- Same name as post, `.jpg` extension
- Example: `2026-02-10_nutrition-for-juniors.jpg`
- Size: 1280×640px (Pollinations.ai output)

### Coach images (static/img/)
- Pattern: `coach_{firstname}.jpg` (lowercase, no spaces)
- Example: `coach_murali.jpg`

### Branch images (static/img/)
- Location: `{ABBREVIATION}_Location.jpg` — e.g. `SES_Location.jpg`
- Schedule: `{ABBREVIATION}_Schedule.jpg` — e.g. `DPS_Schedule.jpg`
- Abbreviations: `SES`, `DPS`, `DIS`, `SIS`, `BSA`, `SBS`

### Tour galleries (static/img/)
- Folder: `DC_{Country}_{Year}/`
- Files: `DC_{Country}_{prefix}_{NNNN}.jpg` — e.g. `DC_Australia_0001.jpg`

### HTML templates
- Template blocks: `{% block content %}`, `{% block extra_head %}`
- Section comments: `<!-- === SECTION NAME === -->`

## 6. CSS Design System

**CRITICAL — never break these colour rules:**

| Background | Required text colour |
|-----------|---------------------|
| Dark blue (`#001f66`, `#003399`) | WHITE (`#ffffff`) or GOLD (`#FFCC00`) |
| White/Grey (`#ffffff`, `#f8fafc`) | DARK BLUE (`#003399`) or DARK GREY (`#0f172a`) |
| Gold (`#FFCC00`) | DARK BLUE (`#003399`) ONLY |

**CSS custom properties (`:root` in `style.css`):**
```css
--blue:       #003399   /* primary brand */
--blue-dark:  #001f66   /* hero/nav backgrounds */
--blue-mid:   #1a4db2   /* mid-tone accents */
--gold:       #FFCC00   /* CTA buttons, highlights */
--gold-dark:  #e6b800   /* gold hover state */
--white:      #ffffff
--gray-100:   #f8fafc   /* page background */
--gray-600:   #475569   /* secondary text */
--text-dark:  #0f172a   /* body text */
```

**Fonts:**
- `Teko` — headings (bold, uppercase)
- `Nunito` — body text (400–900 weight)

**Animation classes** (triggered by Intersection Observer in `main.js`):
- `.fade-in-up` — scroll reveal
- `.card-hover` — hover lift effect
- `.counter` — number count-up on scroll
- `.delay-1`, `.delay-2`, `.delay-3` — staggered delays

**Responsive approach:**
- Mobile-first with Tailwind (`md:`, `lg:` breakpoints)
- `clamp()` for fluid typography
- Hero sections always use inline critical CSS to guarantee dark bg renders before CSS loads

## 7. SEO Architecture

SEO is the primary KPI. Every page change must preserve or improve SEO.

### Metadata flow:
1. `seo()` function in `app.py` builds `meta` dict
2. Falls back to `content/seo.json` for homepage defaults
3. Per-route overrides in each route handler
4. `base.html` renders `<title>`, `<meta>`, Open Graph, Twitter Card, canonical URL

### Blog post metadata:
- Embedded as HTML comment at top of each post file:
  ```html
  <!-- DC_META: {"seo_title":"...", "seo_description":"...", "blog_title":"...", "date":"...", "reading_time":"..."} -->
  ```
- `extract_post_meta()` parses this comment with regex
- Never put metadata anywhere else in blog HTML files

### Schema markup (in `base.html`):
- `SportsOrganization` (main entity)
- `LocalBusiness` (per branch)
- `FAQPage` (common questions)
- Preserve all JSON-LD when editing `base.html`

### Sitemap:
- `/sitemap.xml` is dynamically generated — includes all blog posts
- `/robots.txt` is dynamically generated
- Both routes live in `app.py` — don't make them static files

## 8. Blog Content System

Blog posts are **auto-generated by n8n every Monday 6am UTC**. Do not manually edit files in `content/posts/` unless fixing a specific bug.

### n8n automation flow:
1. Gemini 2.5 Flash generates SEO-optimised HTML blog post
2. Pollinations.ai generates 1280×640 blog banner image
3. n8n commits blog HTML + image to GitHub via API
4. n8n updates `content/seo.json` on GitHub
5. Auto-deploy script pulls changes within 15 minutes
6. Flask webhook `/webhook/update-seo` is called to reload SEO

### Blog slug generation (replicate exactly if needed):
```python
slug_title = re.sub(r'[^a-z0-9\s-]', '', title.lower())
slug_title = re.sub(r'\s+', '-', slug_title.strip())
slug_title = re.sub(r'-+', '-', slug_title)[:60].rstrip('-')
slug = f"{date}_{slug_title}"  # date = YYYY-MM-DD
```

### Safe slug validation (in route handlers):
```python
safe = "".join([c for c in slug if c.isalpha() or c.isdigit() or c in ['-', '_']])
```

## 12. Performance Architecture

### CSS / Tailwind
- Tailwind is **NOT** loaded via CDN JS runtime — that caused 9,710ms TBT on mobile
- `static/css/tailwind.min.css` is a **pre-built static file** (32KB) generated by:
  ```bash
  /tmp/tw-build/node_modules/.bin/tailwindcss -i static/css/tailwind-input.css -o static/css/tailwind.min.css --minify --config tailwind.config.js
  ```
- To regenerate (e.g. after adding new Tailwind classes to templates): run the command above
- `tailwind.config.js` and `tailwind-input.css` are git-ignored (build artefacts)
- Load order in `base.html`: `tailwind.min.css` → `style.css` (style.css overrides Tailwind)

### Fonts & Icons
- Google Fonts and Font Awesome are loaded **non-render-blocking** using the preload/onload pattern:
  ```html
  <link rel="preload" href="..." as="style" onload="this.onload=null;this.rel='stylesheet'">
  ```
- Never revert to `rel="stylesheet"` directly — it blocks first paint

### Images
- All images compressed with ImageMagick in April 2026 (coach: 400px/q80, location: 900px/q82, blog: 800px/q80)
- New images added should be resized before committing:
  - Coach photos: `mogrify -resize 400x -quality 80 static/img/coach_*.jpg`
  - Location/schedule: `mogrify -resize 900x -quality 82 static/img/*_Location.jpg`
  - Blog banners (n8n auto-generates at 1280×640 — compress on add): `mogrify -resize 800x -quality 80`
- Always add `loading="lazy"` to below-fold `<img>` tags
- Hero/LCP image must have `fetchpriority="high"` and `loading="eager"`
- All `<img>` tags need explicit `width` and `height` attributes to prevent CLS

## 14. Common Tasks Cheat Sheet

### Add a new branch/centre:
1. Add entry to `BRANCHES` list in `app.py` following the existing dict structure
2. Add `{ABBR}_Location.jpg` and `{ABBR}_Schedule.jpg` to `static/img/`
3. Add coach images `coach_{firstname}.jpg` to `static/img/`
4. Update sitemap if needed

### Add a new blog post manually:
1. Create `YYYY-MM-DD_slug.html` in `content/posts/`
2. Include `<!-- DC_META: {...} -->` comment at the top
3. Add matching `YYYY-MM-DD_slug.jpg` (1280×640) to `static/img/blog/`

### Update SEO for a page:
- Edit the `seo()` call in the relevant route handler in `app.py`
- For homepage global defaults, edit `content/seo.json`

### Add a new page:
1. Create template in `templates/` extending `base.html`
2. Add route handler to `app.py` following the `seo()` + `render_template()` pattern
3. Add URL to sitemap generation in `/sitemap.xml` route

### Update n8n workflow:
- Edit `n8n_workflow.json` — import into n8n via UI or API
- The workflow uses env vars `GEMINI_API_KEY` and `GITHUB_TOKEN` set in n8n credentials
